# Arcade bracelet API probes

These six images are preserved outputs from bracelet prompts sent to Arcade on October 11, 2026.

Arcade's `/categories/list` response did not include a bracelet, bangle, or cuff manufacturing category. Sending a bracelet prompt without a category succeeded as a generic pattern job, but produced textile-style pattern artwork rather than a manufacturable jewelry product. Sending the same prompt with the Rings category was rejected because the prompt did not refer to a ring.

These files are evidence of that API experiment. The public storefront displays them as clearly labeled **Arcade-generated concept art**, not as bracelet product renders. They are marked **Coming soon**, have no prices, and cannot be added to checkout.

See `probes.json` for Arcade pattern IDs and prompts.
